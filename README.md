# Tensor completion via a novel non-convex minimax $p$-th order concave penalty method
 
This repository implements tensor completion method using minimax $p$-th order concave penalty (MPCP) algorithm [1]. These methods are designed to recover missing entries in multi-dimensional data (tensors).

[1] Zhang, Hongbing and Zheng, bing. (2026). Tensor completion via a novel non-convex minimax $p$-th order concave penalty method.
